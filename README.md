# Resume Upload Demo

A browser demo of the final step in a resume upload flow. Open [index.html](index.html) from a local copy of the repository. The page works without a build step.

Choose or drop a PDF, DOC, or DOCX file, then click **Finish**. The file stays in the browser. **Last step** indicates that this demo covers a single screen.

The layout follows the supplied Figma preview. The illustration uses a region of that preview.
